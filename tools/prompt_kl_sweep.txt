Modern operating systems manage memory through paging: virtual addresses are translated to physical frames by the MMU, and pages not recently used can be evicted to disk. When a process touches an evicted page, the hardware raises a page fault, the kernel loads the data back, and execution resumes transparently. This mechanism lets programs use more memory than physically available, at the cost of unpredictable latency spikes.
